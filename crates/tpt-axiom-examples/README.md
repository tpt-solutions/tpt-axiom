# tpt-axiom-examples

The worked examples for the whole `tpt-axiom` ecosystem, collected in one
crate. Each example documents its expected output in its header and runs in
CI. The index lives in the repository root's [examples README](../../examples/README.md).

Run one with:

```sh
cargo run -p tpt-axiom-examples --example kalman_filter
cargo run -p tpt-axiom-examples --example backend_comparison
```
